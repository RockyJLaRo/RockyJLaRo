- 🎮 **Gaming:** Tibia, game mechanics, client assets, and game preservation.
- 🌐 **Community:** [TibiaWiki Administrator](https://tibia.fandom.com/wiki/User:RockyLaRo), contributing to documentation, maintenance, and technical improvements.
- 🤖 **AI-assisted development:** Regularly use Claude Code, Google Gemini, and ChatGPT to help build, debug, review, and improve projects.
- 🌱 **Currently learning and improving:** Python, C#, JavaScript, web development, automation, and software architecture.
- 🛠️ **Interests:** Open-source software, automation, game tooling, data processing, and making complex tools easier to use.

## 🚀 Featured Projects

### 🧰 Tibia Foundry
A Windows application bringing together tools for managing and inspecting Tibia client data.

- Client version management and organized local archives.
- Tibia DAT and SPR file handling.
- Asset browsing, inspection, conversion, and export.
- Client comparison and change analysis.
- Portable configuration, caching, backups, and diagnostics.

🌐 [Website](https://tibiafoundry.com)

### 📚 Wordtopia / VocabCraft
An educational vocabulary game concept focused on interactive learning, practice challenges, and game-inspired exploration.

### 🧩 Wiki Tools & Automation
Utilities, scripts, and workflows for making wiki maintenance, data organization, and repetitive editing tasks more efficient.
